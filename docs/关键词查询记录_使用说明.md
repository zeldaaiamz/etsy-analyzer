# 关键词查询记录 使用说明（043）

## 是什么
在「获取链接」页输入关键词点 **查询数量** 时，系统自动记一条：关键词 + 查询时间（保存完整时间，显示为几月几日，北京时间）。
记录 **永久保留**：「最近 3 天查找记录」的自动清理、🗑 删除某条历史，都 **不会** 删除它。

## 重复提醒
再次输入同一个关键词（不区分大小写、多余空格忽略，如 `Acrylic  DECORATION` = `acrylic decoration`），点「查询数量」前会弹窗：

> 该关键词在10月18日、10月12日已经查询过

- 多个日期按 **新的在前** 列出，同一天只列一次。
- 点 **仍然查询** 照常提交；点 **取消** 不提交。
- 只看自己账号的记录。

## 导出
「查询数量」旁的 **导出查询记录 CSV**：下载全部记录（关键词、查询时间（北京时间）、来源），Excel 可直接打开。
来源：`sel_count` = 网页查询；`backfill_*` = 上线时从旧数据补回的记录。

## 不能删除
数据库层面禁止删除、修改、清空、删表（触发器 + 权限收回）。如确有错误记录，请联系序猿，不要尝试手工删除。

## 历史补录
上线时会从现有「最近 3 天」任务和「预筛选」里名为「获取链接 <关键词> 第N批」的批次补录更早的查询（每个关键词每天一条）。更早且没送去预筛选的查询无法补录。
